Marketing Ops Email Validator

Drop in your email HTML and see what breaks in each client, with an approximate preview and a deliverability check.

Nothing leaves your browser. The file is read on your own machine.
First time here? Read this
  1. Get the email's HTML, not a screenshot and not a preview link. In your sending platform, look for "view source", "edit HTML" or "export template".
  2. Drag the .html file into the area above, or paste the code, then click Analyze email. If the download comes as a .zip, unzip it first and use the .html file inside.
  3. Start with the errors. Warnings are acceptable degradation in most cases, while errors usually mean somebody is going to receive a broken email.
  4. Use Copy report to hand the issues to whoever coded the email. The report already includes the line number of every occurrence.
  5. The preview is an approximation, not a screenshot from a real client. Before sending to the full list, run a test to a Gmail account, an Outlook account and one on mobile.
